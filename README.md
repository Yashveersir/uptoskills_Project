# AI Learn Platform 🎓

A premium, production-ready online learning platform where world-class skills are taught by AI-generated celebrity mentors.

## 🌟 Key Features

- **AI Celebrity Mentors:** Learn Python, CSS, and MERN Stack from realistic AI personas of personalities like Shah Rukh Khan, Deepika Padukone, and more.
- **Anytime Mentor Switching:** Dynamic persona switching during lessons. Change your virtual teacher instantly without losing progress.
- **Bespoke UI/UX:** A high-end, custom design system inspired by elite platforms, moving away from generic AI-generated boilerplate.
- **Interactive Learning:** Immersive theater-mode lesson player with real-time note-taking and progress tracking.
- **Comprehensive Admin Suite:** Modular dashboard for managing courses, users, and platform analytics with a premium sidebar layout.
- **Production Foundations:** Robust API integration layer (Axios), state persistence (Redux), and role-based security.

## 🚀 Tech Stack

- **Frontend:** React 19, Vite, Tailwind CSS
- **State Management:** Redux Toolkit
- **Routing:** React Router 7
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Notifications:** React Hot Toast

## 🛠️ Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Environment Setup:**
   Create a `.env` file in the root directory:
   ```env
   VITE_API_URL=http://localhost:5000/api
   ```

3. **Development Server:**
   ```bash
   npm run dev
   ```
