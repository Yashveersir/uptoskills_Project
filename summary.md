# AI Learning Platform — Project Summary

## 1. Project Overview

**AI Learn Platform** is a premium, production-ready online learning application where users acquire world-class skills (Python, CSS, MERN Stack) from realistic AI-generated celebrity mentors. The platform offers an immersive, theatrical learning experience with dynamic mentor switching, real-time note-taking, and a comprehensive admin suite for platform management.

**Project Goal:** To provide an elite educational experience by synthesizing well-known personalities into virtual mentors. While the voice and appearance realistically resemble celebrities, the actual teaching content is intelligently generated by AI to ensure high pedagogical standards.

| Feature | Description |

## 5. Core Components & Layouts

### `MainLayout.jsx`
- Wraps all public-facing routes.
- Provides a responsive **Navbar** and **Footer**.
- Uses `Outlet` from React Router to render nested pages.
- Supports dark mode via Tailwind `dark:` classes on the root `div`.

### `AdminLayout.jsx`
- Wraps all admin routes (`/admin/*`).
- Features a **collapsible sidebar** (width toggles between `w-64` and `w-20`).
- Sidebar contains navigation links: Overview, Courses, Users, Analytics, Settings.
- Highlights the active route with a distinct background and indicator dot.
- Bottom section includes an "Exit Admin" button to return to the public site.
- Fully responsive and styled for both light and dark modes.

### `PrivateRoute.jsx`
- A reusable route guard component.
- Checks `isAuthenticated` from the Redux auth state.
- Supports an optional `adminOnly` prop to restrict access based on user `role`.
- Redirects unauthorized users to `/login` (or `/` if they lack admin rights) and displays relevant toast messages.

## 6. State Management & API Layer

### Redux Store (`src/store/index.js`)
- Configured using `configureStore` from Redux Toolkit.
- Currently manages the **`auth` slice**.
- Extensible for future slices (e.g., `courseSlice`, `uiSlice`).

### Auth Slice (`src/store/slices/authSlice.js`)
- **State:** `token`, `role`, `isAuthenticated`.
- **Persistence:** Automatically hydrates from `localStorage` on app load.
- **Actions:**
  - `login(payload)` → Saves token/role to state and `localStorage`.
  - `logout()` → Clears state and `localStorage`.

### Axios Instance (`src/api/axios.js`)
- **Base URL:** Reads from `VITE_API_URL` env variable, falling back to a placeholder if undefined.
- **Request Interceptor:** Dynamically injects the `Bearer` token from the Redux store into the `Authorization` header of every outgoing request.
- **Response Interceptor (Global Error Handling):**
  - **`401 Unauthorized`:** Automatically dispatches `logout()`, shows a toast "Session expired. Please login again.", and redirects to `/login`.
  - **Server Errors (4xx/5xx):** Extracts the error message from the response body and displays it via toast.
  - **Network Errors:** Detects failed requests (no response received) and alerts the user to check their connection.

## 7. Routing & Authentication Flow

### Route Structure (`AppRouter.jsx`)

| Path | Layout | Guard | Component |
|------|--------|-------|-----------|
| `/` | MainLayout | Public | `Home` |
| `/dashboard` | MainLayout | Private | `Dashboard` |
| `/courses` | MainLayout | Private | `Courses` |
| `/courses/:id` | MainLayout | Private | `CourseDetails` |
| `/watch/:id` | MainLayout | Private | `WatchCourse` |
| `/admin` | AdminLayout | Private (Admin) | `AdminOverview` |
| `/admin/courses` | AdminLayout | Private (Admin) | `AdminCourses` |
| `/admin/users` | AdminLayout | Private (Admin) | `AdminUsers` |
| `/admin/analytics` | AdminLayout | Private (Admin) | `AdminAnalytics` |
| `/admin/settings` | AdminLayout | Private (Admin) | `AdminSettings` |
| `/login`, `/register`, `/forgot-password` | None | Public | Auth Forms |
| `*` | None | Public | `NotFound` |

### Authentication Flow
1. **Login:** User submits credentials → API returns `token` and `role` → `login` action dispatched → `localStorage` updated → User redirected to protected route.
2. **Session Check:** On app refresh, `authSlice` reads `localStorage` to restore session.
3. **Token Expiry:** API returns `401` → Axios interceptor catches it → `logout` action dispatched → User redirected to `/login`.
4. **Admin Check:** Routes wrapped with `<PrivateRoute adminOnly>` verify `role === "admin"`. Non-admins are redirected to `/`.

## 10. Future Scope & Notes

- **Backend Integration:** The frontend is ready for a full REST API. The `api/` folder and Axios interceptors are structured for production use.
- **State Expansion:** The Redux store can easily be extended with `courseSlice`, `userSlice`, or `mentorSlice` as the backend data model grows.
- **Testing:** Consider adding **Vitest** or **Jest** + **React Testing Library** for unit and integration tests.
- **PWA:** Can be converted into a Progressive Web App using Vite's `vite-plugin-pwa`.
- **Performance:** Leverage React 19's concurrent features (e.g., `Suspense`, `useDeferredValue`) for heavy data-fetching routes.
- **Accessibility:** Ensure proper ARIA labels and keyboard navigation are maintained across dynamic components like the Admin Sidebar.
